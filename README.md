# Лабораторная работа №3 (Вариант 8)

**Тема:** Фабрика по сборке мебельных гарнитуров.

## Реализованный функционал:
- Абстрактные классы (`AbstractEntity`, `AbstractRepository`)
- Хранилище в `List` и `Map` (`ListRepository`, `MapRepository`)
- Чтение/запись TXT, XML (DOM), JSON (Gson)
- Шифрование (MD5 + AES)
- Архивация (ZIP)
- UNIT-тесты (JUnit 5)

## Как запустить:
1. Открыть проект в IntelliJ IDEA.
2. Запустить `Main.java` (класс `com.lab3.Main`).
3. Тесты запускаются командой `mvn test` или через IDEA.
